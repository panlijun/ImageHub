# 实现架构：真实本地图库与 M1

业务基线 IH-SRS-001 1.1；技术基线 IH-TS-001 1.0。资源包保持原样。

当前实现包括永久副本导入、分页图库与整理、处理输出/永久保存/桌面导出、账号安全存储、持久上传任务、普通链接与主动检测、合并/替换备份恢复、持久设置和本机诊断。Windows 全部 90 条 V1 仍是目标；缓存/空间、网络类型策略和上传前自动处理依赖已接入；远端删除及全部必要平台/服务/人工验收仍待完成。

## 边界与数据真相

`domain` 保留不可变资产、内容版本和本机副本；`application` 接收批次意图并提供真实逐项结果；`data` 负责 Drift、文件日志及单一写入协调；`platform` 取得系统资源与应用目录；Riverpod 控制器连接这些边界；桌面 A 展示数据库已确认的资产。

资产、版本、副本、导入操作分别使用 UUID。内容身份为 SHA-256 与实际字节数；来源名称、位置及扩展名不决定身份。去重不会覆盖旧名称、分类、收藏、回收状态与未来历史关联。文件与照片入口只是取得资源，永久字节与它们的访问寿命分离。

应用使用 Application Support 下全新 `imagehost_library_v1/`。`library.sqlite` 只管理新数据；`originals/` 保管原样字节；`staging/` 接收尚未提交的写入；`cache/thumbnails/` 是可再生预览。应用不能扫描旧项目数据位置。

## 跨资源提交

1. 数据库写入独立导入意图，并持有目录写入锁。
2. 逐项流式写入暂存文件，关闭并 flush，计算 SHA-256，再重读验证。
3. 在 isolate 识别真实格式、验证解码、取得方向正确的尺寸；拒绝损坏/不支持/超候选资源预算的输入。永久文件不做方向或元数据改写。
4. 持久记录 ready 元信息，在同一文件系统发布到 UUID 管理路径。
5. 数据库事务提交版本、资产、副本关联，移除操作意图；之后才向 UI 报告保存成功。

文件系统与 SQLite 没有共同事务。恢复必须核对意图、暂存/最终字节和摘要：writing 不可用；ready 有完整校验证据才可以幂等完成提交。不从文件名推断可用，不自动清库，不删除无日志依据的文件。未完成操作在新启动时提供真实恢复说明。正常提交后，来源文件即使被移动或删除也不影响副本。

SQLite 明确验证外键、WAL、FULL。未来 schema、损坏库、锁冲突和加载失败进入阻止写入的错误状态并允许重试。FULL/flush 不等于所有硬件断电绝对保证；本轮故障注入不能冒充实机断电。

## 展示及平台

桌面 A 采用左导航、图库网格、右检查区；窄桌面从详情入口查看。未实现目的地显示不可用状态，不能模拟队列/账号/上传。分页逐步读取元数据，可见图片异步检查副本及生成缩略图。缓存失败可重试，不回滚已经永久保存的图片。

用户于 2026-10-04 选定 M1 图库优先并接受优化方向。Flutter 按 Android/iOS 主题平台选择 M1，桌面窄窗口仍采用 A。M1 使用共同资料库与导入协调器，具备两/三列图库、真实名称搜索/收藏筛选、多选核对和详情；链接完整页仍待接入，任务入口打开共同上传页。独立 `design/mobile-m1/` 仍是设计参考。系统文件和照片插件被薄适配器隔离，不把桌面绝对路径视为平台资源协议。

`GalleryQuery` 同时约束数据库计数、分页、全匹配身份查询；参数绑定和 SQLite 注册的 TextPolicy 完整 Unicode 折叠函数执行名称、来源、格式、分类和标签的字面子串检索。分类/多个标签/来源/格式/最近校验可用性/收藏取交集。名称、大小和导入时间以 UUID 破同值；上传时间暂没有真实结果，UI 禁止选择，不造时间。控制器以查询修订号拒绝迟到分页，并防止并发分页；分页期间总数变化则读取新的首批，避免错过资产。

schema 2 为新项目自身添加 Categories、Tags、AssetTags、FileLeases、VersionReferences、PurgeOperations 和 LibraryMetadata。原 schema 1 分类显示名以共同规范合并后迁成 UUID 外键；所有迁移在事务中完成，失败保留原关联及版本。元信息批次先校验全部身份、分类和每资产 50 标签限额，再整批写入；草稿只在提交时 trim/NFC/full fold/NFC，64 字符按 Unicode scalar 计。

回收只改变资产可见性与回收时间，恢复保留身份与整理。30 天仅产生提示。永久字节和记录分开确认；清记录保留内容版本和字节，下一次导入创建新资产，复用或修复孤立副本。复用提交保留 committedReuse 清理意图，清理失败不将已提交资产报为失败。清字节先持久写入清除日志，严格验证管理路径和共享引用，再删除文件和事务更新实际状态；中断可幂等重试。

短期文件租约和持久版本依赖分别保存；取消意图不释放租约，只有实际 IO 结束才能释放。关闭先排空正在取得租约的操作，再在协调门之外等待释放。拿到独占目录锁后仅清除前进程临时租约，持久依赖保留；导入不能替换仍在使用的内容路径。当前持久引用是共同保护接口，不能据六种 ownerType 宣称六项业务均已接入。

手机选择集保存 UUID，筛选变化不修改它；全选捕获当时查询的全部匹配身份，核对面板按 UUID 查询真实名称。搜索去抖等待期间暂停依赖当前结果的选择操作。详情验证永久副本后才报可用，收藏持久化失败与刷新失败分别反馈。M1 工具入口与桌面导航共用处理、账号和任务页；成功链接完整检索仍未接入。

## 后续边界

ImageProcessor 在可终止 isolate 中读取、校验、处理、编码，再校验输出和输入；取消等待线程退出后才清理结果。压缩不放大小图，裁剪使用视觉方向整数区域，拼接保留确认顺序和实际尺寸；PNG/JPEG/WebP 输出，动画显式选帧和静态转换，丢透明需确认背景，损失与体积增加如实记录。默认清除私密元数据并保留受支持颜色声明；RGB matrix/TRC ICC 已净化并验证容器，LUT/CMYK/HDR、不同颜色空间拼接明确拒绝。预算仍是候选值，未完成设备校准。

schema 3 增加 ProcessedOutputs、OutputReferences、OutputLeases、SavedOutputOrigins，并给 ImportOperations 添加输出来源外键。来源快照只保存管理目录相对路径和稳定身份，不保存外部授权或绝对位置。新项目自身 1/2→3 事务升级保留资产/版本/副本和整理；schema 2 文本规范不兼容在升级前拒绝。

ProcessingCoordinator 先取得来源实际文件租约，再冻结策略并保存 writing 意图；isolate 完成编码后校验实际字节/格式/尺寸、flush、保存 prepared 元信息、同卷发布，最后才设 ready。writing 半成品重开成为失败，prepared 只有复核后才完成；异常记录不当作空库。结果读取时重新校验 SHA/字节，只有 ready 且可用才提供文件。动画裁剪预览通过相同选帧的独立缩略图呈现。

永久保存沿用 ImportOperations 日志与暂存协议，最终关联事务同时提交永久内容与 SavedOutputOrigins；去重保留已有整理。保存未完成意图阻止临时清理，重开可恢复；来源关系独立保存，即使临时结果删除仍可说明来源版本和参数。永久副本不引用临时路径。

输出默认 24 小时，可选 1 小时/7 天。启动、可运行期间每分钟及手动请求只清到期、无持久引用/活动租约/未完成保存的管理文件。先持久设 deleting，再实际删除和事务移除记录；失败保留可重试。成功永久保存为独立字节，其来源标记不是临时字节的永久依赖；真正依赖临时文件的 permanent 引用仍阻止清理。schema 5 上传项在创建时保留持久来源保护，执行租约只在实际 IO 收尾后释放；重开先恢复上传，再尝试输出到期清理。

FileExporter 与 ExportGateway 分开：桌面系统选择目录，共同流式复制以 exclusive create 避让同名，关闭、目标和源摘要校验后逐项报成功；取消/失败关闭实际 IO 后只尝试清除证据一致的本次目标，疑点替换文件保留。macOS 用户所选文件配置为读写；Apple 未验证。移动必须采用已选原生 API，目前明确禁用。Dart 路径 API 的检查不能充当针对恶意外部程序的原子 no-follow/file-id 平台保证。

当前可见工作页负责系统退出，图库在处理或账号页打开时注销退出监听；停止需等待实际工作和租约释放再关闭库。备份恢复、空间管理和队列剩余条件继续按资源包实现。账号系统秘密存储已有合成凭据测试，没有真实图床请求或应用云账户。

schema 4 的 ProviderTargets/CredentialOperations 为共同账号配置保存稳定身份及跨秘密存储恢复意图。秘密值仅经纯 Dart SecretStore 接口进入平台 SystemSecretStore；生产 provider 注入，命令行恢复工具无原生后端时拒绝凭据操作。写入采用新 UUID 引用，安全写入并读回后关联，清旧引用失败保留日志。删除先停用并保留去敏身份，再清理秘密；会话凭据不落盘，替代旧持久引用后不能重开复活旧值。账号页在后台实际操作结束后才关闭库，与图库退出监听互斥。

SecretRedactor 注册值、敏感结构键及 URL 等分别处理；账号别名、上传历史、普通结果、备份及本机诊断已有接线，全部未来出口仍须逐一验证。2026-10-05 授权补齐 ATL 后，Windows 原生合成凭据写/资料库重开读/删子流程与账号版 Release 启动退出通过；其他三端仅源配置。真实队列与账号变更通知已接线，默认服务契约未知时仍禁止派发。

上传基础分为独立 CatboxAdapter/ImgBBAdapter、纯领域响应结果与 QueuePolicy。适配器只解释协议和传输证据，不决定重试，不写数据库或宣称历史已保存。默认精确限制 unknown 时不派发；受控测试注入的限制只属于测试夹具。取消完成必须等待实际 fetch、本机读流与底层响应流停止，网络响应预算为 64 KiB，不记录原始请求/响应或异常。管理秘密只在受保护的运行时包装中传给后续 SecretStore 提交流程，不能变成普通 URL。

QueuePolicy 保留需求九种状态及转换、六种聚合与五类计数，终态不可被迟到事件改写。AutomaticRetryPolicy 只在有无不确定副作用证据时返回 2/4/8 秒或更长服务端等待，最多四次执行。TimeSource 分离 UTC 审计和 Stopwatch 单调时间；ExecutionBudget 跨尝试累计实际执行、忽略等待并按实际增加的字节活动计算 120 秒/30 分钟边界。UploadCoordinator 接入实际看门计时器、持久累计检查点和有界派发，降并发不强杀在途项；恢复保守重新等待完整退避时长，不以墙钟提前唤醒。

schema 5 新增 UploadBatches、UploadPublications、UploadAttempts、RemoteUploadResults、UploadResultOperations、UploadEvents。入队整批验证输入与目标，以意图 UUID 幂等创建，并在同一事务保留输入版本/处理输出保护；任务冻结去敏名称、目标 UUID、输入摘要、策略哈希和独立审计摘要。派发重新解析当前目标凭据，在持久请求授权标记前复查身份与代次。重开把旧运行尝试按是否可能发送恢复为 interrupted 或 unknown，不自动重发未知结果。

成功响应先形成可恢复的普通结果提案；管理秘密写入受保护新 UUID 引用并读回核对摘要，最后关联普通结果、尝试和任务终态。结果按尝试身份唯一，取消先成立时晚到确认仍可独立保存但不改取消计数。后发现的管理秘密注册后在关联事务中遮蔽本库所有历史展示快照；重开仅读取本库引用进行注册，安全后端故障不能恢复已经遮蔽的文本。

LibrarySession 持有 UploadCoordinator，页面离开不关队列。桌面与 M1 打开共同上传页；默认上传前自动处理，从工作台进入保留确认输出选择；原图另需隐私确认。入队与网络授权分离，仅本次会话允许网络。实际执行和源文件租约须等真实传输收尾，收尾失败保留保护并拒绝伪报安全退出。默认服务限制未知时保持能力等待，受控测试传输不代表生产服务已验证。网络类型与派发策略已接线，实机切换PT、远端删除与完整服务证据仍须补齐。

设计差异：手机规格第2条的单调 ID 是原型样本机制，依其实施边界和更高优先级 DAT-003/T-15，生产采用 UUID；这不改变身份不复用的业务要求。

备份新增独立领域 Manifest、快照租约、导出协调器、STORE ZIP 写入和只读恢复预检。图库在唯一写入门内取得一致关系和永久版本租约，长摘要/像素及归档工作在门外完成。导出不是整库序列化，不包含设备路径或可执行意图；所有本库秘密先注册，结构值无法安全脱敏时拒绝该包。实际版本保留 PNG/JPEG/WebP/GIF/BMP 标识，容器后缀小写。

Windows 平台通过一个窄 MethodChannel 查询当前用户可用空间，并将所选目标目录中的私有归档用 MoveFileExW 无覆盖地发布；共同协调器不直接依赖 Win32。ZIP 预检先复制到自有暂存并验证原始目录，检查重复条目/链接/越界、实际累计大小、CRC/SHA 与真实像素，再返回受控临时文件；预检不会改当前库。默认合并和独立确认的替换均已接入实际持久提交，不能将预检结果称为恢复成功。

BackupRestorePlanner 基于永久合并计划，对路径无关来源、账号身份、普通确认及终态历史统一重映射；当前活动尝试及临时输出身份也参与保护。相同摘要/大小但图片描述矛盾以及超过 50 个标签的并集阻止提交。去敏快照用于安全计划和操作日志，不允许改写现有本机整理名称或账号配置。

RestoreCoordinator 先在临时位置预检，再依次获取 UploadRestoreHold 与 LibraryRestoreHold，显示实际提议并等待确认。资料库保护拒绝新普通调用，排空已接受调用和真实租约；等待不占写入门。文件复制在门外执行但由实际恢复 drain 保护退出与根锁；元信息及日志 committed 在同一事务内确认。所有位置先验证后清理，归属不确定保留日志，不自动恢复网络或批次。

schema 6 新增 RestoreOperations、RestoredOutputOrigins、ImportedUploadHistories。导入来源仅含可携带参数与内容身份，导入历史仅为审计；新账号禁用、无秘密，普通结果不带管理能力。完整副本独占发布到当前设备新 UUID 位置，元数据副本标记 missing；后续完整修复保留 copy UUID。见 [实际合并恢复](milestone-10-merge-restore.md)。

内部 ReplacementSnapshot 在同一个维护保护下取得 SQLite VACUUM INTO 一致副本和实际登记文件字节，比较当前全部 28 表/结构/摘要，单独标记 missing。私有数据库保留真实本机关系和受保护 UUID 引用，不进入可携带 Manifest；凭据值仍由 SecretStore 保管。确认替换前，在全新私有临时位置实际重建数据库/图片并再次读取校验，不只校验快照清单。RestoreOperations 复用严格阶段及 unclaimed/owned 目录归属；未确认归属或未知内容保留现场。

替换为所有传入版本分配新本机副本位置，保持备份资产/版本/关联身份，不经过内容合并。新副本关闭、摘要/像素校验和独占发布后，一笔 SQLite 事务更新业务关系及 replace-committed；提交前旧字节和凭据保持原值。失败用启用 URI 的局部独立 SQLite 连接只读 ATTACH 快照，在现有维护/写入门中单事务恢复全关系。启动先处理替换日志，再进行其他维护；未能安全回滚时保留证据并拒绝普通读写。提交后核对旧引用与摘要才清文件/秘密，replace-cleaned 在删除私有快照前持久化，使中断清理可继续。

LibraryUploadQueueStore 固定运行会话，Zone 保留异步调用会话，写入门二次检查；UploadExecution 的结果确认另检查会话。关闭、重开和替换事务确认使旧执行对象失效。替换取消旧可执行意图、清内存凭据及重建上传 actor；保护释放后刷新查询、选择和账号/任务页面，网络须重新授权。实际结果与限制见 [替换恢复](milestone-12-replacement-restore.md)。

LinkResultQuery 在 SQL 层组合 ordinary 名称/URL/冻结历史目标、稳定目标身份、服务及原图/处理类型，计数与分页同谓词，主值相同结果 UUID 升序收尾。秘密新增注册使 SecretRedactor.revision 变化，首次后续查询在 writer 内事务遮蔽旧普通快照后再匹配；历史目标 SQL 窗口每个身份只返回一个最新冻结描述。没有索引系统秘密或将当前同名配置映射为旧目标。

LinkCopyPlan 是仓储 owner/epoch 绑定的内存确认能力，冻结明确 UUID 顺序、格式化结果、跳过/去重计数及普通字段摘要。LinkTransferCoordinator 执行前重新验证，只把普通文本交给平台 gateway；失败、取消、无法确认等反馈不改变远程结果，也不创建上传。平台用 Flutter 的严格剪贴板协议与 share_plus 文本入口，系统行为与平台回执单独验证。

## 独立远端删除（UPL-007）

RemoteDeletionPlan绑定仓储owner/epoch、当前普通结果完整摘要及当前目标代次，不含授权值。Repository按同目标UUID重新解析受保护或明确会话凭据，验证Catbox账号身份、严格单文件标识和精确普通直链；begin与请求前再次复验。独立的RemoteDeletionCoordinator只接受网络和远端删除两项确认，无构造请求、自动重试或重开执行。关闭会话先同步阻止新请求，再取消并等待实际IO。

使用既有LibraryMetadata的remote_delete_v1/UUID格式1保存prepared/sending/notSent/unknown；仅身份、摘要、分类、时间及安全HTTP状态，不含请求授权、秘密引用、URL或响应。请求前一笔事务记录sending并将此前可访问观察置unknown/interrupted，保留lastAccessible；普通结果、字节、秘密及任务均不删除。拿到新进程资料库排他锁后，prepared记未发送、sending记未知，无网络重放；未知版本/畸形记录拒绝打开且保留原值。

DioRemoteDeletionGateway固定Catbox HTTPS multipart POST，deletefiles/userhash/单文件files，禁重定向、日志及重试；原始响应累计16KiB后停止，正文丢弃。当前公开文档未定义可靠的删除成功响应，因此派发后任何HTTP/空或文本正文均unknown，HTTP200不表示已删除；20秒/16KiB为候选预算。适配器跟踪真实delegate.fetch、multipart源订阅和原始响应订阅，全部结束后才返回；清理无法确认时抛固定异常，保留仓储保护并拒绝关闭/恢复。恢复及关闭在writer门外等待，不把取消当作IO完成。

图库链接页在桌面A/M1共同提供单文件独立确认、取消、最新持久审计和缺能力说明；本地移除仍0远端请求。探测及本地结果移除不能与未收尾删除交错。可携带包不含本机删除审计；合并保留当前审计，替换关联事务清旧审计，私有快照/故障回滚保留原记录，防止同UUID备份结果误挂旧本机动作。schema10/28表与Manifest2不变。具体验证及实际服务/设备缺口见 [删除阶段记录](milestone-24-remote-deletion.md)。
