## 当前实现

- 共同设置增加缩略图磁盘容量（默认 256 MiB，整数 64–2048）与新输出默认保留时间（1 小时/24 小时/7 天）。DeviceSettings 自身格式 2；严格读取自身格式 1 并使用新增默认值，不自动重写旧记录。未来格式和损坏仍拒绝加载。
- 设置进入共同空间页面。真实库内普通文件长度按永久、回收、仅清记录后保留字节、缩略图、临时结果、暂存、数据库和未登记文件分开统计。诊断内容字节单列，不重复计入总文件字节。文件长度不是文件系统分配簇占用；扫描也不是正在写入文件的原子快照。
- 可再生缩略图在既有 LibraryMetadata 持久登记，不改 schema 8/27 表。独立 UUID 路径、源版本内容/帧绑定、SHA/字节校验、持久使用序号 LRU、容量及显示保护。未知文件和链接保留；仅凭内容相同不能证明发布归属。
- writing/prepared/published/ready/deleting 记录控制独占暂存、发布和恢复。原生发布成功后先持久 published；prepared 遇已存在目标不接管或删除，阻止后续新增缓存。原生调用成功与 SQL 确认之间的进程中断仍保留未知现场，不猜测归属。低层 Dart 测试的 rename 后备不代表生产原生独占发布契约。
- 图库实际取得缩略图使用保护，摘要读取后交 Image.memory；释放等真实读取结束。真实读取另参与关闭及恢复 drain，单纯显示保护不阻止正常关闭。
- 明确冻结范围并确认后清缩略图，后来的缓存不增清，使用变化须重新核对，受保护/篡改/未登记文件保留。临时结果入口只调用实际执行时已到期且无保护的既有清理；日志入口复用真实诊断页。
- 生产仓储注入真实平台空间接口，导入前和每个实际写入块检查；处理在输出意图前检查候选输出预算。未知探测失败停止新增相关写入。32 MiB 余量及处理估算是候选防护参数，不是四端实测。
- Windows 复用已有 GetDiskFreeSpaceExW/MoveFileExW。Android StatFs、Apple statfs 与独占 link/unlink 原生源码和 Apple PrivacyInfo 已接线，尚未构建或设备验证。Application Support 基目录先解析系统路径别名再添加本应用独立命名空间。
- Flutter 解码内存缓存单独设候选数量/字节预算，不能据此声称全应用内存或 live image 被限制。

生产变更主要位于 `app/lib/features/storage/`、`features/gallery/data/library_storage.dart` 及仓储/预览接线、共同设置、处理默认值、逐块文件复制和 `platform/storage_capacity.dart`。原生平台变更在 Android MainActivity、Apple Runner 入口和隐私清单。测试位于缓存/仓储/设置/空间页及平台协议测试文件。
