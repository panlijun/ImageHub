# ImageHost 手机 UI 规格

版本 2.1 · 2026-10-03 · 当前内容源：mobile.js、mobile.css。桌面 A 已选；旧手机稿已否定。Figma 尚未同步本轮修正，当前规格优先于旧画布。

## 设计目标

让个人用户从已保管图片出发，清楚完成找图、处理、保存、上传及链接回访。图片占据主要视觉面积；少用装饰和大型统计卡。导航是长期回访目的地，处理与上传是依赖具体选图的动作。设计取舍及实施边界见 [设计实施说明](../implementation-notes.md)。

两方案共用中性色与蓝色动作、语义状态、文件行、图片素材和业务规则，结构不同：M1 默认图库与三项底栏；M2 默认发布工作台与顺序步骤，无底栏。推荐 M1 是产品判断，没有效率实测支撑。

## 页面与导航

| 场景 | M1 | M2 |
| --- | --- | --- |
| 打开 | 三列连续图库；搜索、筛选、选择与导入 | 当前/新建发布批次；图库、链接、任务入口 |
| 多选 | 顶部选中计数；底部压缩、拼接、上传上下文动作 | 二列选图，全图库可滚动，搜索、取消、全选、导入 |
| 单图 | 详情、收藏、远程结果、删除本机记录 | 从图库或最近保存进入相同业务详情 |
| 处理 | 独立暗色画布与参数；退出可保留 | 可选流程步骤；可跳过并明确上传原图 |
| 上传确认 | 弹层列出实际文件、版本和图床 | 专门页面列出对象、版本和图床 |
| 结果 | 任务目的地与详情、链接回访 | 发布回执、工作台历史入口 |
| 返回 | 实际页面历史；底栏切换稳定目的地 | 返回当前流程或工作台，不借用 M1 底栏 |

工具菜单包含图库、链接、任务、账号、设置、继续/清空处理批次。清空批次仅清除操作上下文，永久图片和远程记录保留。

## 核心状态规则

1. 导入获取独立本机副本后成为图库对象。原型用合成样本模拟这一步；用户原文件保留。照片受限可改文件来源，云照片获取失败可重试。
2. 图片 ID 单调分配，删除后不会重用。处理版本使用独立 versionId。不存在的图片不可静默替换为另一张。
3. 批次保留选图、处理方式、格式、尺寸、比例、拼接顺序/间距、已生成结果、保存及导出状态。参数或输入改变使旧临时输出作废；已保存副本及已上传结果保留。
4. 压缩每张选图生成一个结果；裁剪生成当前单图结果；拼接生成一个结果，来源包含全部选图且顺序可上移、下移或反转。
5. 本原型支持静态 WebP、JPEG、PNG 输出示意。JPEG 遇 PNG 来源须确认白色背景；动画不进入这个静态流程。真实透明度检测、方向/元数据及编解码按需求文档后续实现。
6. 保存只对当前输出执行一次，追加独立图库副本；重复按钮禁用。首次失败保留临时输出，可以重试或导出。导出与上传均不表示已经永久保存。
7. 上传入口显式指定原图、临时处理结果或已保存处理副本。上一次输出不会替换新选原图。版本 × 目标拥有独立远程记录；记录快照不依赖后来当前编辑参数。
8. 结果聚合只计算当前批次项目。历史批次保留并可回访。重试只创建失败目标的新尝试，原失败记录保留；成功链接不改变。待确认项不能自动重试，确认重复风险后新建上传，旧记录仍待确认。
9. 详情、任务和链接使用同一结果来源。链接仅展示成功项；URL/Markdown/HTML/BBCode 使用实际结果文件扩展名并转义替代文本。HTML同时转义URL属性，查询分隔符不改变普通URL或已有百分号编码。复制为反馈模拟。
10. 等待联网、待确认和演示中的活跃任务依赖阻止删除；处理草稿的输入及已保存输出同样保护，清空批次后可解除相应草稿依赖。删除仅移除本机图库对象，用户原文件与远程结果保留。
11. 清理只演示过期缓存，永久图片、已保存结果及活跃依赖保留。备份恢复、诊断、设置均有独立入口，不把远程图床上传称为应用云同步。

## 账号身份与结果检索

新增图床配置和编辑原配置分别进入弹层。必需名称和演示凭据缺失时不创建账号；修复或改名仍使用原稳定身份，只有新增才分配新身份。同名账号允许存在，以服务、别名及非秘密目标标记区分。匿名目标没有账号凭据。

保存模拟配置标记未验证，只有已授权上传的模拟结果才显示“模拟上传成功”；不执行官方健康验证，也不保存输入的示例字符串。账号启用仅进入选择集合，不自动勾选或追溯加入批次。停用/移除展示当前结果集合中的等待项数量，阻止后续模拟派发。已暂停项需要用户继续。等待授权条件的原型内部状态 authorization 对应正式需求 waiting 加授权等待原因，不是新增生产状态。

发布项在创建时保存服务与别名快照；改名只影响新批次。移除配置保留去敏身份、旧名称和成功 URL，原目标等待项不能改派新同名配置。此时说明可取消剩余排队后另建发布，已有成功项继续保留。部分成功与取消混合仍显示部分成功；全部取消才显示已取消。

链接页只检索成功结果；关键词对名称、普通 URL、历史目标名称和版本说明不区分大小写匹配。关键词、稳定目标身份及原图/处理版本筛选取交集，和图库的检索状态独立。移除配置的历史目标仍在筛选选项中。当前原型按结果记录编号倒序显示；“最新结果”指新的结果记录，不表示真实确认时间排序已经实现。批量复制先展示当前可见集合及顺序供确认，不混入失败、待确认或被筛掉的记录。正式排序与复制规则见 LIB-006、LNK-001/002。

新增字段不会指定正式数据库表或生产接口，Flutter 选型与四端产品边界保持既定结果。

## 视觉与适配

基础颜色：背景 #f5f6f8，正文 #172033，次要文字 #586779，动作 #285bd4；成功 #166b48、警告 #925315、失败 #ad302b。暗色处理页 #141920。图片呈现使用合成九宫格素材，未复制参考产品界面或商标资产。

桌面预览宽390，高度随内容；实际窄屏占满可用宽度。M1图库三列，M2选图两列；长文件名在详情换行，选图列表可截断但可进入详情。44 CSS像素为此原型最低可操作目标，常规按钮48；不能直接等同四端物理触控尺寸已验收。

弹层标记对话框与 aria-modal，背景 inert，Tab/Shift+Tab 在弹层内循环，Escape 关闭并恢复触发入口焦点。状态不单靠颜色表示；图标提供文字或可访问名称。提示不拦截指针操作。正式 Flutter 的无障碍树、缩放、读屏和系统返回需独立设备验证。
