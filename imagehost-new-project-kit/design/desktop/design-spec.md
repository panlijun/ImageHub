# 桌面 A 实施规格

状态：用户已选定｜用途：新 Flutter 桌面界面设计参考

工作界面由左侧目的地导航、顶部工具栏、图库内容和右侧所选图片检查区构成。主要页面是图库、图片处理、上传任务、图床账号和设置；搜索/筛选、多选批量动作依附于当前内容，不作为新的主导航目的地。

- 图库使用网格/列表，图片是主要视觉对象。检查区显示所选版本、整理信息和逐目标结果；窄桌面窗可通过详情入口呈现检查区内容。
- 处理使用独立预览与参数区，明确输入版本、处理参数和当前输出。生成、永久保存、导出、上传分别操作与反馈；原图保持独立。
- 上传任务显示各图片版本与各目标的结果、错误原因和恢复动作。部分成功、待确认、授权等待和用户暂停不能简化为一个进度条。
- 图床账号支持同平台多账号、新增/编辑、未验证、启停/移除、稳定身份及历史名称快照。桌面样本中的简化账号逻辑不能覆盖需求1.1。
- 设置包含存储、缓存、备份恢复、诊断及设备级偏好。必要的风险确认与失败恢复与手机遵循同一业务规则。

视觉采取中性底色、单一蓝色主动作及语义状态色，保持紧凑工具风格。以可运行 index.html 为桌面 A 的布局和视觉参考，以 [共同设计说明](../implementation-notes.md)、[需求](../../documents/requirements-analysis.md) 和当前手机共同状态规则补全其历史行为简化。

本包已移除桌面 B/C 的选择入口及样式、旧手机入口与手机布局；桌面样本按760 CSS像素以上宽度查看。真实 Flutter 的最小窗口、缩放、触控与键盘规则按需求和平台实际验证，不把这个预览阈值当作新业务需求。

所有图片/队列/文件/凭据与处理结果均为模拟。不要从样本推导真实性能或复制其内存数据模型。正式应用的桌面数据保留、恢复、图片编解码及系统交互尚未实现或验收。
