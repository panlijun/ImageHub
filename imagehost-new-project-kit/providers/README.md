# 首版图床接入约定

整理/官方资料核查日期：2026-10-04｜初始服务：[Catbox](catbox.md)、[ImgBB](imgbb.md)

这是面向全新 Flutter 项目的协议说明，不沿用旧 TypeScript/Rust 接口、代码位置或历史测试通过结论。两个既定图床保留；Cloudinary 等未来候选不进入首版或本包。

## 适配边界

每个服务独立实现 ProviderAdapter，负责能力声明、请求构造、限制校验、成功响应归一化和去敏错误。图库、队列和 UI 不解析服务专用 JSON，也不凭图床名字决定能力。

输入至少包含具体版本、有效受保护的本机文件、文件名/MIME/长度/摘要、稳定目标身份与本次授权引用。目标名称可以相同，身份不可复用；创建上传时保存去敏名称快照，后续改名/移除不会改写历史结果。

输出保留服务与目标身份、版本身份、本次尝试、普通直接链接、可用的远端标识/展示链接及确认时间。删除管理链接、密钥和原始秘密响应不能进入普通链接页、同步、元数据备份或诊断。普通响应保存遵守需求的白名单与去敏规则，不直接落完整含秘密响应。

无安全无副作用验证端点时，不通过偷偷上传验证账号。排队任务仍使用原目标条件；新建同名账号不能接管旧任务。传输进度或HTTP返回本身不代表可用链接确认成功。

## 能力与失败

认证/额度/限流/网络/不支持输入/服务故障/用户取消/远端结果未确认分开处理，只有可靠证据才能判定结果。发送后中断可能已在远端成功，归入需求规定的待确认流程；不把所有网络错误都自动重试。

首版不承诺服务通用远端列表、配额查询、断点续传、重复上传幂等、程序化删除或永久托管。Catbox 账号删除和 ImgBB 管理链接各自按服务能力提供可选入口，不能简化成统一 deleteRemote=true。应用本机删除不自动删除远端文件。

## 实现与验证

使用已选 Dio 与受保护秘密存储，不把 API key 放入日志、地址栏演示链接或普通数据库字段。按 unit-test-design.md 映射请求构造、成功/异常解析、超限、取消、待确认、账号删除/改名和去敏用例；官方服务联调需单列契约/集成证据。

实现前复核官方限制和当前服务条件，固定能力数据及其核查日期。实际认证与网络可用性不能由本说明或旧应用冒烟结果替代。用户未提供授权测试资源时，先完成替身验证，不能使用私有照片或真实秘密进行试上传。
